# 2026-11-27 实验数据交接

压缩包按用途分组。下载对应的 ZIP，解压到独立目录。各包保留原实验目录结构，可合并解压。用 `manifest.json` 确认包内路径、数量和 SHA-256。

| 包名前缀 | 内容 |
|---|---|
| `ladder` | 天梯系列赛、逐局归属、官方回放、换版及训练轮次记录 |
| `online` | 官网练习、正式评测成绩、回放、SDK 逐帧观测、采样计划与地图划分 |
| `local-eval` | 本地评测、双线训练报告、逐局成绩、专项诊断及训练作业 |
| `specialist` | 基础及终极人机专项的历史实验、模型和验证结果 |
| `snapshots` | 参赛策略快照、源码和权重，按快照 ID 查找 |

`tables/` 里的 JSONL 是从工作台数据库导出的逐行数据。天梯用 `series_id` 串起系列赛，`game_id` 对应回放文件名。官网练习记录的对局 ID 可对应 SDK 观测和回放。同一局有观测和回放时，统计局数按对局 ID 去重。本地评测的 `matches.jsonl` 以 `case_id` 为键，`spec` 记录版本、地图和出生侧。

导出保留官网队伍数字 ID，去掉账号凭据、房间码、私人身份信息和本机绝对路径。原始校验值用于追溯源文件。脱敏后文件的完整性以本次压缩包 SHA-256 为准。仍在跑的批次在各自文件或数据库读入时截取。
