# 游击规划

初赛 40 局达到 10,000 分需要场均 250。按 SDK 2.6 的计分，击毁、伤害合计最多 100 分，此外取决于剩余生命和提前结束的秒数。例如打满伤害、击毁对手、剩余 80 血、在第 20 秒结束，恰好得到 250 分。

地图上沿四邻格查到目标的最短路，复用同一目标格的距离表。方法参考 [Red Blob Games 的网格搜索](https://www.redblobgames.com/pathfinding/a-star/implementation.html)。是否能直接攻击复用 SDK 的墙体判定。视线打通后，按最近两帧观测预测目标位置，利用装填间隔横移；来弹接近时在游戏网格上比较未来 8 帧内可执行的动作。缩圈后优先回到安全区。
