# 终极档陪练实测

本页记录初版。后续的多批官网采样、逐弹诊断和新地图盲测见[终极档行为复现实验](./终极档行为复现实验.md)。

## 数据与模型

陪练模仿官网练习房「终极练习人机」。训练使用 3 张地图上的 11 场、6,325 帧，覆盖起始规则、示范学习和游击策略的多个版本。按整张地图划分数据。地图 96671 的两场只用来检验动作，地图 8107 和 44917 只用来比较排名。

回放含双方位置、朝向、装填、发射计数和场上物体。用相邻帧恢复可辨识的动作，碰墙时无法判断的进退样本不计算移动损失。模型分别预测进退、转向和发射意图，临近装填完成时结合目标移动方向修正瞄准。两场动作验证的进退分类正确率为 64.26%，转向平均绝对误差为每帧 10.53°，可开火帧的发射精确率和召回率分别为 84.62% 和 89.19%。[逐帧数据提取](../training/fit_boss_sparring.py) · [初版训练清单和指标](https://github.com/gluttonsama-cloud/tank/blob/33c6fd0afb5413a5af21b7bf63b353ef2bd2cbc1/strategies/boss-sparring/training.json)

## 回圈修正

游击策略按 3 秒后的圈半径提前绕墙回圈，在可选躲弹动作中计入未来的圈伤。固定对手、10 张独立地图上各换边一次，旧版和新版累计圈伤 174.0 → 20.4，得分 1,524.50 → 1,588.00，均为 6 胜。两者受弹伤害分别为 1,643.8 和 1,810.0。

复测原失分地图 1200500144 时，为隔离改动，使用对局 14053 的转向预测版本，仅更改回圈逻辑。同图红方圈伤 33.6 → 0，得分 46.4 → 163.3。另一次换蓝方得 50 分，圈伤 0。此消融版本与排名表中的主线回圈版是不同快照。[原对局](https://tank.dian.org.cn/replay/14053) · [同图同侧](https://tank.dian.org.cn/replay/14163) · [换边](https://tank.dian.org.cn/replay/14168)

## 版本排序

4 个版本各打 2 张留出地图，每图红、蓝各 1 局。下表为这 4 局的我方场均得分。官网终极档在两张图上分别计算，排序都相同。

| 我方版本 | 官网终极档 | 本地近似陪练 | SDK 入门对照 |
|---|---:|---:|---:|
| 转向预测与避弹 | 80.95 | 243.95 | 253.93 |
| 游击初版 | 57.25 | 248.28 | 262.98 |
| 提前回圈、兼顾躲弹 | 37.50 | 248.28 | 262.98 |
| 起始规则 | 7.50 | 163.10 | 166.35 |

6 对版本比较中，近似陪练与官网同序 3 对、反序 2 对、打平 1 对，SDK 入门对照也得到同样的结果。3 对同序全部来自识别起始规则最弱。3 个游击版本在本地对近似陪练的 12 场全部在 15.2–26.7 秒结束，官网对应对局持续 83.4–90 秒。模型在交战初期就让局面偏离了官网，尤其测不出回圈差异。

这 4 场官网留出对局中，主线游击初版累计圈伤 81.0、回圈版 0，两者场均得分分别为 57.25 和 37.50。回圈版保留为独立候选；近似陪练可用于本地批量对局，此版不能给相近策略排强弱。

## 复现

回放保存在 `.local/online/replays/<对局编号>.json.gz`。训练作业 `train-29c0091479da4c1cbff924f3b6c2281f` 导出的快照为 `v-bd574ebaa672affd93587a8c98e0acd015f8cdfb589587743c55a755fd32def1`。以下命令在项目根目录的 PowerShell 运行。

```powershell
$meta = (git show 33c6fd0:strategies/boss-sparring/training.json | Out-String) | ConvertFrom-Json
$trainParams = @{ train_ids = @($meta.train.id); holdout_ids = @($meta.holdout.id); epochs = $meta.epochs; policy = 'legacy' } | ConvertTo-Json -Compress
$inputs = foreach ($game in @($meta.train) + @($meta.holdout)) { '--input'; ".local/online/replays/$($game.id).json.gz" }
$config = .\.venv\Scripts\tank.exe jobs configure --opponent baseline=1 --seed $meta.seed --json | ConvertFrom-Json
.\.venv\Scripts\tank.exe jobs start fit_boss_sparring.py --config $config.config_id @inputs --params $trainParams --json
```

复算排名时在同一工作区运行以下命令。陪练快照自带训练及动作验证清单，脚本会核对留出地图、出生点与游戏局号。报告列出每场分数、圈伤、时长和各版本的两两对照。

```powershell
$versions = @(
    'v-e14eb6d871988e74c79bae052828dbd8caef4ecb8a07cb248160094910da108f',
    'v-0081349ee9d189d06bc534ecdac22f731b4908714c90b45644a1962aea0583f5',
    'v-347bb1bc7deb8f248847596bcc9594f637c81178ab1b24da4defd5e5e015987f',
    'v-afb2273b543f0b869ecdecde648acdf2563db4b1f3574c9454142012adf298d6'
)
$model = 'v-bd574ebaa672affd93587a8c98e0acd015f8cdfb589587743c55a755fd32def1'
.\.venv\Scripts\python -B training/compare_boss.py --opponent $model --candidates @versions --seeds 8107 44917 --output .local/online/benchmarks/boss-v1.json
```
