# 在线采样

## 队伍共用一个练习入口

选白天开机的电脑作主机，在工作台保存官网账号。主机从仓库根目录运行下列命令，把地址换成本机校园网 IP。

```powershell
tank sample host-serve --host <主机校园网IP> --port 8767 --background --json
```

把主机地址和返回的 `token_path` 文件里的组内令牌私下交给队友。队友在各自仓库运行一次，按提示输入令牌。

```powershell
tank sample host-use http://<主机校园网IP>:8767
```

队友从工作台或 `tank online practice` 开练习，按到达顺序使用比赛账号。采样用独立账号，两支官网队伍可以同时开房。如果两个账号实际对应同一支官网队伍，队友优先。主机上没有的策略由发起端运行，练习期间保持发起端在线。

用 `tank sample host-stop` 停止队友的练习服务，用同一条 `host-serve` 命令重启。客户端断线后用 `tank sample host-result <请求ID> --json` 取回已完成的对局。

## 采集与导出

在采集主机运行一次 `tank sample account --username <学号>`，按提示输入密码。开练习房、收取回放都用这个账号。凭据保存在主机的 `.local/`。练习使用官方 SDK 发送动作，无需上传策略包。更换采集账号时先暂停任务，配置后用原任务 ID 续采。

```powershell
tank sample start --target boss --maps 4 --json
tank sample start --target boss --continuous --json
tank sample list --json
tank sample status <采样ID> --json
tank sample pause <采样ID> --json
tank sample resume <采样ID> --json
tank sample export --target boss --run <采样ID> --json
tank sample export --target boss --split train --out .local/behavior/train.json --json
```

前两条任选其一。默认每张地图选三种打法，每种各打红蓝一局，4 张地图共 24 局。同一任务固定策略快照、地图种子和出生侧。换边时让过位，续跑只把缺少的一侧计入该组。用 `--seed 123 --probes approach silent` 可指定同图对照。

新建终极档任务时，每 4 张图都测接近开火。其中 1 张同测停火和间歇开火，另 3 张都测游击，并依次搭配撤退、探头、缩圈回撤。游击用于增加后半局，接近开火用于观察人机连续受击后的动作。

导出摘要给出场次、不同地图数及实际遇到的局面。看 `coverage.games_with` 能知道多少场出现近距离、丢失视线、缩圈结束后仍存活，或有敌弹时发生横移。横移按回放坐标计算，不能单凭这项判断是否成功躲弹。

带 `--out` 的清单逐局标明官网 ID、红蓝双方、模仿对象所在一侧 `target_side`、我方已知快照、地图、分组和原始回放路径。相同地图布局固定进入同一组。终极档沿用原实验的训练、开发和盲测地图，新地图按布局哈希分组。用 `--run` 限制到本批、用 `--split train` 导出训练输入。原始回放和索引位于主机的 `.local/online/replays/` 和 `.local/sampling/`。

## 采样打法

| 参数 | 主动制造的局面 |
|---|---|
| `approach` / `silent` / `pulse` | 相同导航接近，分别允许开火、全程停火、每 3 秒切换开火许可。比较对方在有无弹压时的走位。 |
| `retreat` | 看见对方后边打边退，观察是否追击、追到多近。 |
| `peek` | 绕墙探头后尝试退回掩体，观察丢失和重新获得视线时的反应。 |
| `late-zone` | 在外围拖至缩圈并回撤，增加观察后半局进圈的机会。 |
| `lancer` | 用实战游击策略交手，补充多种行为混合出现的局面。 |

## 收集其他队伍的回放

用 `tank sample freeze peek pulse --json` 取出相同采样打法的快照和入口，可用于队伍约战。被动采集只读取官网已有对局，不占用 SDK 练习席位。

```powershell
tank sample watch --target team:123 --interval 60 --json
tank sample pull --target team:123 --json
tank sample import 对局.json.gz --target team:123 --json
tank sample export --target team:123 --split train --out .local/behavior/team-123.json --json
```

`watch` 持续收取本队与指定队伍的完赛回放，`pull` 只收一次。官网接口返回本队最近 200 条记录，手头已有的完整回放可用 `import` 补录。按正式队伍 ID 识别目标，换边后仍标出正确的模仿对象；同一对局对同一目标只收录一次。

练习房生命周期、换边和回放字段按[官方 SDK 0.4.3](https://tank.dian.org.cn/sdk/seedcup-0.4.3-py3-none-any.whl) 实现。地图分组沿用[终极档行为复现实验](./终极档行为复现实验.md)。

官网实测中，终极档采样先完成红侧 15645，队友的普通练习 15653 插入并取得回放，随后补齐蓝侧 15665。另用仅存于发起工作区的策略跑了 15777，149 帧推进中我方出现 141 个不同位置、开火 10 次；发起端和主机保存的回放字节一致。
